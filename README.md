# 🌿 Plant Disease Detection using MobileNetV2

An AI-powered Plant Disease Detection system built using **TensorFlow**, **Keras**, and **MobileNetV2**. This project leverages **Transfer Learning** to accurately classify plant leaf diseases from images, helping in early disease identification and improving agricultural productivity.

---

## 🚀 Features

- 🌱 Detects plant diseases from leaf images
- 🧠 Transfer Learning with MobileNetV2
- 📊 Image preprocessing and data augmentation
- ⚡ Fast and accurate prediction
- 🖼️ Supports image-based disease classification
- 📈 Trained on the PlantVillage dataset
- 💾 Pre-trained model included (`plant_disease_model.keras`)

## 📊 Dataset

**Dataset:** PlantVillage Dataset

- Total Images: **41,000+**
- Disease Classes: **16**
- Image Size: **224 × 224**
- Training: **80%**
- Validation: **20%**
